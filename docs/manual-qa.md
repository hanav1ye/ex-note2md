# 手動QAチェックリスト

自動テスト（`npm test`）は jsdom 上で動くため、以下は実ブラウザでしか確認できない。
リリース前に実機で一通り確認する。

## 準備

1. `npm run build:dist` を実行する
2. `chrome://extensions`（Edge は `edge://extensions`）でデベロッパーモードを有効化
3. **`dist/` フォルダ**を「パッケージ化されていない拡張機能を読み込む」で読み込む（リポジトリのルートではなく dist を読み込むこと。提出物と同じものを確認するため）

## 基本の変換

- [ ] note 記事ページを開き、popup に記事タイトルが表示される
- [ ] note 記事ページ以外で popup を開くと、その旨のメッセージが出る
- [ ] 「現在のタブ」+「コピー」で変換 → クリップボードに Markdown が入る
- [ ] 「URL を指定」+「コピー」で同じ記事を変換 → **タブ変換の結果と一致する**
- [ ] 変換結果を Obsidian に貼り付け、frontmatter と本文が壊れていない

## ダウンロード

- [ ] プリセット未設定の状態でダウンロードするとエラーメッセージが出る
- [ ] オプション画面でフォルダを設定 → popup のプリセット選択に反映される
- [ ] ダウンロード実行 → 指定フォルダに `{note ID}.md` が保存される
- [ ] 同じ記事をもう一度ダウンロード → 上書き保存の通知が出る

## フォルダ権限（自動テスト不可）

- [ ] フォルダ設定後にブラウザを再起動し、オプション画面を開く
- [ ] 権限が失効していれば「アクセスを再許可」ボタンが表示される
- [ ] ボタンを押して許可 → ボタンが消え、ダウンロードが成功する
- [ ] 設定したフォルダをOS側で削除・移動した場合、「見つかりません」と表示される

## リンク選択（popup が閉じる挙動の確認）

- [ ] note の記事一覧ページで「選択する」を押す → popup が閉じ、ページにトーストが出る
- [ ] 記事リンクをクリック → **ページ上で変換が実行され、結果のトーストが出る**
- [ ] 選択モード中に **Esc** を押すと終了し、以降クリックしても変換されない
- [ ] 記事リンク以外（プロフィールなど）をクリックしても何も起きない

## 複数選択・一括処理

- [ ] 「複数選択」→ 複数の記事リンクをクリック → パネルの件数が増える
- [ ] 「一覧を全選択」→ プロフィール / 仕事依頼が除外されている
- [ ] 「実行」→ 順番に処理され、進捗が表示される
- [ ] 実行中に「中止」→ 現在の記事の処理後に停止し、未処理分だけがパネルに残る
- [ ] 中止後に「実行」→ 残りが処理される
- [ ] 実行中に **Esc** → 終了ではなく中止として扱われる（パネルが残る）
- [ ] パネルのボタンがページ側のスタイルに影響されず表示されている

## 画像取込方式

- [ ] 「note URL参照」→ Markdown に note の画像URLが入る
- [ ] 「画像ダウンロード」→ 画像保存先に `{note ID}/img1.png` 形式で保存され、Markdown が相対パスを参照する
- [ ] 画像フォルダ未設定で「画像ダウンロード」を実行するとエラーメッセージが出る
- [ ] 「Base64埋込」→ Markdown に data URI が埋め込まれる（ファイルサイズに注意）

## タグ / タグセット

- [ ] オプション画面でタグ候補を追加 → popup にチェックボックスとして出る
- [ ] タグを5つ選んだ状態で6つ目を選ぶとエラーメッセージが出る
- [ ] タグセットを登録 → popup のタグセット選択に出る
- [ ] タグセットを選ぶとチェックが一括で切り替わる
- [ ] 手動でチェックを変えるとタグセット選択が「選択なし」に戻る
- [ ] 選択したタグが frontmatter の `tags` に出力される

## Obsidian リンク化

- [ ] リンク化ワードを登録し、ON にして変換 → 本文中の一致ワードが `[[単語]]` になる
- [ ] コードブロック・インラインコード・既存リンク・既存 `[[...]]` が変換されない

## 異常系

- [ ] 有料記事や本文が取得できない記事でエラーメッセージが出る（クラッシュしない）
- [ ] オフライン状態で URL 変換を実行するとエラーメッセージが出る
- [ ] 一括処理の途中で1件失敗しても、残りの処理が続行される

## 最終確認

- [ ] `chrome://extensions` の「エラー」欄に何も出ていない
- [ ] Service Worker のコンソールに想定外のエラーが出ていない
- [ ] popup / オプション画面のコンソールにエラーが出ていない
